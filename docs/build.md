# Build configuration

The GNU Make build reads the `config.mk` generated by
[nvccoptions](https://github.com/naoto-aoki-fy/nvccoptions). Generate it in the
compiler environment used for this project:

```sh
git clone https://github.com/naoto-aoki-fy/nvccoptions.git
make -C nvccoptions
cp nvccoptions/config.mk .
make
```

See the nvccoptions documentation for compiler environment selection and
configuration generation on machines without a GPU. The generated configuration
is machine-specific and is ignored by Git. Regenerate it when the compiler
environment or target GPU architectures change.

Alternatively, read the configuration directly from its original location:

```sh
make CONFIG_MK=/path/to/nvccoptions/config.mk
```

The Makefile uses `NVCC` to compile and link, `CFLAGS_VENDOR` for compilation,
`LDFLAGS_VENDOR` for linking, and `GENCODE_FLAGS` for GPU architectures. Exported
environment variables in the configuration are preserved. CUDA runtime linking
is handled by `nvcc`. Compilation requires C++17 and defaults to `-O3`.

Additional options can be supplied through `CPPFLAGS`, `NVCCFLAGS`, `LDFLAGS`,
and `LDLIBS`, for example:

```sh
make NVCCFLAGS="-O0 -g -G"
```

Run `make clean` before rebuilding with different command-line options or a
different configuration path. Changes to the included configuration file,
Makefile, source, or compiler-generated header dependencies trigger a rebuild.

The executable is `build/cuda_state_vector`. `make clean` removes the build
directory and works even without `config.mk`; it preserves the configuration.
